# 🏏 IPL Data Analysis

## 📖 Overview

This project performs **Exploratory Data Analysis (EDA)** on the Indian Premier League (IPL) dataset using Python. The analysis focuses on understanding team performance, player statistics, toss decisions, venue impact, and overall match trends through data visualization.

---

## 🎯 Objectives

- Clean and preprocess the IPL dataset.
- Explore team and player performances.
- Analyze toss and match-winning patterns.
- Visualize important statistics using charts.
- Generate meaningful insights from the data.

---

## 📌 Key Insights

- Certain teams consistently performed better across multiple seasons.
- Winning the toss does not always guarantee winning the match.
- Some players received significantly more Player of the Match awards.
- Match venues influenced team performances in several cases.
- Data visualization helps identify trends that are difficult to observe from raw data.
